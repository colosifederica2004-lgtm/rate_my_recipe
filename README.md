# Rate My Recipe

## Project Overview

Rate My Recipe is a Python data analysis project based on the Food.com Recipes and Interactions dataset.

The project aims to develop a fair ranking of recipes based on user ratings, taking into account the number of reviews associated with each recipe.

## Research Question

How can recipes be ranked fairly according to user ratings while accounting for differences in the number of reviews?

## Objectives

- Explore and prepare the recipe and user interaction datasets.
- Develop a ranking strategy that considers both ratings and review counts.
- Compare the proposed ranking with a simple ranking based on average ratings.
- Investigate how rankings vary across recipe characteristics, such as tags, preparation time and number of ingredients, where the data allow.
- Present the analysis through visualisations and an interactive Streamlit application.

## Project Structure

- `data/`: datasets used in the project.
- `notebooks/`: notebooks documenting the analysis.
- `recipe_project/`: reusable Python modules.
- `pages/`: additional Streamlit pages.
- `app.py`: main Streamlit application.

## Technologies

Python, pandas, NumPy, SciPy, Matplotlib, Seaborn and Streamlit.
